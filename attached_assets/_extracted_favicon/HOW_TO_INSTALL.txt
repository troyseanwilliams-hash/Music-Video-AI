AI Beat Sync — favicon set
==========================
Drop these into: artifacts/beatvision/public/

Files:
  favicon.svg                 - scalable (modern browsers)
  favicon.ico                 - 16/32/48/64 multi-size (legacy)
  favicon-16x16.png
  favicon-32x32.png
  favicon-96x96.png
  apple-touch-icon.png        - 180x180 (iOS home screen)
  android-chrome-192x192.png
  android-chrome-512x512.png  - also used for PWA / Open Graph fallback
  favicon.png                 - 512x512 generic (replaces existing public/favicon.png)

In artifacts/beatvision/index.html <head>, ensure:
  <link rel="icon" type="image/svg+xml" href="/favicon.svg" />
  <link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png" />
  <link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png" />
  <link rel="icon" href="/favicon.ico" sizes="any" />
  <link rel="apple-touch-icon" href="/apple-touch-icon.png" />

In public/manifest.json, point icons to android-chrome-192x192.png and android-chrome-512x512.png.
