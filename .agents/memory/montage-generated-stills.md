---
name: Image-first video foundations
description: Product and billing rules for automatic persisted source images in standard video generation.
---

Every ordinary **Visual Montage** and **Narrative Story** video begins with an immutable, owner-protected source-image plan. Montage creates one reusable image per planned visual motif; Narrative creates one distinct image per chronological scene. The separate Images only product remains independently selectable.

Narrative Generate must also allow the user to choose an already-created gallery image as the exact source for each scene, not merely as a character reference. Selected scenes skip image generation and its charge; animation remains paid.

**Why:** The user explicitly requested restoration of the former saved-image scene workflow.

**How to apply:** Keep per-scene source selection separate from the optional character reference. Changing a selection requires renewed script approval; invalidating the scene plan clears its selections.

Images only must remain a standalone Generate-page section, not a video structure or setting. Plan one focused scene per requested image; its optional character reference conditions only the planned scenes that actually feature that character.

Every image-generation request represents one requested segment. Its server-side prompt must explicitly require one continuous composition and prohibit multi-panel, collage, storyboard, or montage output.

When a character reference is supplied for a story, apply it only to automatically identified character-focused scenes. Environment, object, transition, and atmosphere scenes must not receive the reference input.

**Why:** Generating video from a predefined image foundation keeps settings and subjects coherent across segments. Montage remains affordable by reusing its bounded motif library, while Narrative’s story promise requires one non-repeating visual per scene.

**How to apply:** Reserve and show the configured per-image credit charge separately from animation cost. Persist every image and its path before video provider calls; use Montage’s timeline only when sequencing completed motif clips, never while choosing which unique clip to animate. Keep Images only free of video/audio controls, persist one scene plan per requested image, and only pass a selected character reference to eligible pack scenes. For video storyboards, persist the same per-scene reference relevance. Apply the single-scene guard in every image provider request. Make images visible on job status and usable in Remix Lab. Do not expose provider names in product copy.
