---
name: Generate character continuity
description: Optional character-reference behavior for cohesive narrative video generation.
---

Generate accepts one natural-language script or premise and may also accept an optional uploaded or gallery-selected character reference. A reference is never required; when none is attached, the generated text character bible provides continuity.

**Why:** Generate should remain a simple cohesive story workflow while still letting users anchor a recurring character's appearance when visual identity matters.

**How to apply:** Keep the Character Reference control visible in Generate and preserve its object path through preview planning, job submission, and persistence. Apply it only to storyboard scenes that actually feature the character; environment-only and generic scenes remain independent. Do not restore the Visual Montage structure selector.
